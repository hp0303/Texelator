# Texelator v0.2.0

This release makes Texelator usable as a terminal chat runtime on native Windows 11,
Linux, and WSL2.

**Supported published model:**
[Qwen3.8-27B Texelator AW-BC4](https://huggingface.co/hp0303/Qwen3.8-27B-Texelator-AWBC4)

**Paper:** [Texelator PDF](https://github.com/hp0303/Texelator/blob/v0.2.0/research/paper/Texelator.pdf)

> **This is an early alpha release. Bug reports and hardware compatibility reports
> are strongly encouraged.** Please open a
> [GitHub issue](https://github.com/hp0303/Texelator/issues) with the full command and
> log, GPU, driver, CUDA Toolkit, operating system, and model ID. Do not skip a failed
> setup, benchmark, or correctness stage.

## Highlights

- Native Windows PowerShell installer, validated on an RTX 5080.
- One shared published AW-BC4 model path for validated RTX 40/50 hardware palettes.
- Mandatory correctness-checked K benchmark once per model/GPU pair.
- Explicit `pull`, `benchmark`, `run`, and activation-aware `ptq` commands.
- Thinking mode is off by default and can be toggled from the CLI.
- No Texelator-imposed default response-token cap.
- Research paper and compact public measurements are separated under `research/`.

## Native Windows

Download `texelator-v0.2.0-windows.zip`, extract it, and run in PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
.\texelator.cmd pull qwen3.8:27b
.\texelator.cmd benchmark qwen3.8:27b
.\texelator.cmd run qwen3.8:27b
```

Required: Windows 11 x64, current NVIDIA driver, Python 3.10--3.14 x64,
Visual Studio 2022 **Desktop development with C++**, and CUDA Toolkit 12.8.

The ZIP contains source code and builds a local native CUDA extension. Model weights
are downloaded separately and are not included in the GitHub Release.

## Ubuntu or WSL2

Download and extract `texelator-v0.2.0-linux-wsl2.zip`, then run from the extracted
`texelator` directory:

```bash
sudo apt update
sudo apt install -y python3-venv python3-dev build-essential
bash scripts/install.sh
source .venv/bin/activate
texelator pull qwen3.8:27b
texelator benchmark qwen3.8:27b
texelator run qwen3.8:27b
```

Required: a current NVIDIA driver, a visible CUDA-capable RTX GPU, and a CUDA toolkit
containing `nvcc`. CUDA Toolkit 12.8 is the validated configuration. The same commands
apply inside WSL2 with NVIDIA GPU passthrough enabled.
