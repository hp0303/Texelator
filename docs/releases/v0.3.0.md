# Texelator v0.3.0

This release makes the quality-preserving BF16 Texture IteratorB prefill autotuner
the default and includes an explicitly experimental MLP-only FP4 speed path.

**Featured model:** [Qwen3.8-27B BF16-calibrated AW-BC4](https://huggingface.co/hp0303/Qwen3.8-27B-Texelator-AWBC4-BF16Cal)

**Paper:** [Texelator PDF](https://github.com/hp0303/Texelator/blob/v0.3.0/research/paper/Texelator.pdf)

## Highlights

- BF16 prefill autotunes five bitwise-equivalent CUTLASS Texture IteratorB tiles per
  model/GPU and stores a hardware- and kernel-specific profile.
- RTX 5080 Qwen3.8-27B 512-token prefill improved from 599.8 ms to 475.4 ms
  (853.6 to 1076.9 token/s) with bitwise-identical full-model output.
- `--prefill-mode fp4` exposes the validated MLP-only staged FP4 experiment. It is
  faster but not quality-equivalent and remains disabled by default.
- RTX 5080 now selects a separately published BF16-source/BF16-calibrated model.

## Windows 11

Download `texelator-v0.3.0-windows.zip`, extract it, open PowerShell in the extracted
folder, and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
.\texelator.cmd pull qwen3.8:27b
.\texelator.cmd benchmark qwen3.8:27b
.\texelator.cmd run qwen3.8:27b
```

## Linux / Ubuntu / WSL2

Download and extract `texelator-v0.3.0-linux-wsl2.zip`, then run:

```bash
bash scripts/install.sh
source .venv/bin/activate
texelator pull qwen3.8:27b
texelator benchmark qwen3.8:27b
texelator run qwen3.8:27b
```

The first benchmark is mandatory. It tunes both decode and BF16 prefill for the
actual GPU. CUDA Toolkit 12.8 or newer and a current NVIDIA driver are required.

## FP4 warning

The optional FP4 mode measured 1325.8 token/s versus 1066.1 token/s for BF16 at a
512-token prompt on RTX 5080, but hidden-state cosine was 0.872 and RRMS was 0.507.
It is included for research and performance experimentation only.

Texelator remains early alpha. Bug reports with the full command, log, GPU, driver,
CUDA version, OS, and model ID are especially welcome.
